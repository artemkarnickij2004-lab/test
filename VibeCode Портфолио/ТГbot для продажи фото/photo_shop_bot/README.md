# ✦ ЛУМИН — Telegram-бот для продажи фотографий

Готовая фотолавка в Telegram: покупатели листают каталог красивыми карточками,
оплачивают звёздами ⭐ в два касания и мгновенно получают оригинал
в полном качестве без водяного знака.

**Что внутри**

- 🖼 **Каталог-карусель** — карточки с превью под водяным знаком, навигация «◀️ ▶️»
- ⭐ **Оплата звёздами Telegram** — официальный способ продажи цифровых товаров: подключать ничего не нужно
- 📥 **Мгновенная выдача** — оригинал прилетает файлом (без сжатия) сразу после оплаты
- 🛍 **«Мои покупки»** — личная коллекция с повторным скачиванием в любой момент
- 🛠 **Админ-панель** — добавление работ прямо в чате за 4 шага, удаление, статистика продаж
- 🎨 **Автовотермарк** — диагональный водяной знак + подпись лавки накладываются сами
- 💾 **SQLite** — ничего не нужно поднимать, база создаётся сама

```
photo_shop_bot/
├── bot.py               # точка входа
├── config.py            # настройки + .env
├── db.py                # база данных SQLite
├── texts.py             # ВСЕ тексты бота — оформление меняется тут
├── keyboards.py         # кнопки
├── watermark.py         # водяной знак (Pillow)
├── states.py            # шаги добавления фото
├── handlers/            # логика: start, catalog, payments, profile, admin
├── assets/
│   ├── logo.png         # аватарка бота и заставка /start
│   └── demo/            # 3 демо-фотографии для каталога
├── storage/             # оригиналы, превью, shop.db (создаётся само)
├── seed_demo.py         # заполнение демо-каталога
├── requirements.txt
└── .env.example
```

## 🚀 Запуск за 5 шагов

### Шаг 1. Создаём бота у @BotFather

1. Откройте в Telegram **[@BotFather](https://t.me/BotFather)** → `/newbot`
2. Придумайте имя: `ЛУМИН • фотолавка`
3. Придумайте username (обязательно заканчивается на `bot`): например `lumin_photo_bot`
4. BotFather пришлёт **токен** вида `123456:AAE...` — сохраните его

### Шаг 2. Красиво оформляем профиль бота

Всё это делается в том же диалоге с @BotFather — просто отправляйте команды по очереди:

| Команда | Что вставить |
|---|---|
| `/setuserpic` | загрузите файл **`assets/logo.png`** из этого проекта |
| `/setname` | `ЛУМИН • фотолавка` |
| `/setabouttext` | `Авторские фотографии за звёзды Telegram ⭐ Оригинал в полном качестве — сразу после оплаты.` |
| `/setdescription` | текст ниже 👇 |

Текст для `/setdescription` (его видят все, кто открывает бота первый раз):

```
✦ Добро пожаловать в ЛУМИН!

Здесь продают не картинки, а свет: городские вечера, туманные утра
и тишину между кадрами.

Выберите фотографию, оплатите звёздами ⭐ — и оригинал в полном
качестве без водяного знака станет вашим за пару секунд.

Нажмите /start
```

Команды меню (кнопка «Меню» рядом с полем ввода) — `/setcommands`:

```
start - 🏠 Главное меню
catalog - 🖼 Каталог работ
purchases - 🛍 Мои покупки
```

### Шаг 3. Токен и права администратора

1. Узнайте свой числовой ID у **[@userinfobot](https://t.me/userinfobot)**
2. В папке проекта скопируйте `.env.example` → `.env` и заполните:

```env
BOT_TOKEN=сюда_токен_от_BotFather
ADMIN_IDS=сюда_ваш_ID
SHOP_NAME=ЛУМИН
SUPPORT_USERNAME=@ваш_телеграм
```

> Несколько админов — через запятую: `ADMIN_IDS=111111,222222`

### Шаг 4. Установка и запуск

Нужен **Python 3.10+**:

```bash
cd photo_shop_bot
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

python seed_demo.py             # по желанию: наполнить каталог 3 демо-фото
python bot.py
```

Увидели в консоли `Бот @... запущен ✦` — всё работает! Напишите боту `/start`.

### Шаг 5. Наполняем каталог своими фото

Откройте бота и отправьте `/admin` (кнопка «🛠 Админ-панель» есть и в главном меню — видна только вам).

**➕ Добавить фото** — мастер за 4 шага: фото → название → описание → цена в звёздах.

> 💡 **Важно про качество:** отправляйте фотографию **файлом** (скрепка → «Файл», без сжатия) — тогда покупатель получит настоящий полноразмерный оригинал. Водяной знак на превью бот наложит сам.

## ⭐ Про деньги: как устроена оплата звёздами

- **Подключать ничего не нужно.** Инвойсы в звёздах (валюта `XTR`) работают у любого бота из коробки — в коде уже всё готово.
- Для **цифровых товаров** (фото, гайды, доступы) правила Telegram разрешают **только звёзды** — это ваш случай, всё по правилам. Рублёвые платежи через ЮKassa/Stripe нужны только для физических товаров.
- **Где деньги:** баланс звёзд смотрите в @BotFather → `/mybots` → ваш бот → **Payments** → Telegram Stars. Вывод — через [Fragment](https://fragment.com) (звёзды обмениваются на TON или тратятся на рекламу Telegram).
- **Комиссия:** при выводе Telegram удерживает ~15 %, учитывайте это в цене.
- **Протестировать покупку:** заведите тестовую работу за 1 ⭐ и купите её сами с другого аккаунта.
- **Возвраты** делаются методом Bot API `refundStarPayment` — в таблице `purchases` хранится `charge_id` каждой оплаты. Структура проекта позволяет добавить команду «вернуть» буквально в 15 строк.

## ✨ Как это выглядит для покупателя

1. `/start` — заставка с логотипом и атмосферным приветствием
2. **🖼 Каталог** — листает работы стрелками; у каждой: превью с водяным знаком, описание, цена
3. **«⭐ Купить за 99 ⭐»** — нативное окно оплаты Telegram, Face ID — готово
4. Оригинал прилетает **файлом** (полное разрешение, EXIF на месте), карточка сама меняется на «📥 Скачать оригинал»
5. Все покупки живут в **«🛍 Мои покупки»** — скачать повторно можно когда угодно

## 🎨 Настройка под себя

| Хотите | Где менять |
|---|---|
| Другие тексты и стиль | **texts.py** — все фразы бота в одном месте |
| Название лавки / водяной знак | `SHOP_NAME` в `.env` |
| Другой логотип | замените `assets/logo.png` (и `/setuserpic` у BotFather) |
| Вид водяного знака (угол, прозрачность, текст) | аргументы `make_watermark()` в **watermark.py** |
| Кнопки | **keyboards.py** |

Чтобы **начать с чистого каталога**: удалите в `/admin` → «📋 Работы» демо-фото, либо остановите бота и сотрите `storage/shop.db` + содержимое `storage/originals` и `storage/previews`.

## 🖥 Работа 24/7 на сервере (VPS)

Перенесите папку на сервер и создайте сервис `/etc/systemd/system/luminbot.service`:

```ini
[Unit]
Description=Lumin photo shop bot
After=network.target

[Service]
WorkingDirectory=/opt/photo_shop_bot
ExecStart=/opt/photo_shop_bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now luminbot
journalctl -u luminbot -f   # смотреть логи
```

Подойдёт самый дешёвый VPS — или просто включённый домашний компьютер/Raspberry Pi.

## ❓ FAQ

**Бот не отвечает.** Проверьте, что `BOT_TOKEN` в `.env` без пробелов и кавычек; что запущен только один экземпляр бота (второй `python bot.py` с тем же токеном вызовет конфликт).

**Не вижу админку.** Убедитесь, что `ADMIN_IDS` — именно числовой ID (его даёт @userinfobot), а не username. После смены `.env` перезапустите бота.

**Фото не загружается.** Telegram Bot API позволяет скачивать файлы до 20 МБ — норма даже для 50-мегапиксельных RAW-экспортов в JPEG, просто имейте в виду.

**Основные файлы лежат где?** Оригиналы — `storage/originals/`, превью с водяным знаком — `storage/previews/`, база — `storage/shop.db`. Папку `storage/` стоит бэкапить.

**Это законно?** Продавайте только свои работы или фото, на которые у вас есть права. В тексте «О лавке» уже прописано, что покупатель получает файл для личного использования.
