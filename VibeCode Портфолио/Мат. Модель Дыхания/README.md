# Дыхание человека — интерактивная модель

Минималистичная учебная модель: вентиляция лёгких → газообмен в альвеолах → перенос кислорода эритроцитами → доставка клеткам организма.

**Есть два интерфейса с одной и той же моделью расчётов на Python:**

- **Оконный, полностью на Python/Tkinter** — анимация и интерфейс работают без браузера и без JavaScript.
- **Браузерный** — расчёты выполняет Python, браузер плавно отрисовывает схему.

Не нужны интернет, `pip install` или сторонние Python-библиотеки. Нужен **Python 3.10 или новее**. Для оконного интерфейса также нужен Tkinter; обычно он уже есть в официальной установке Python.

## Быстрый запуск

1. Распакуйте **весь архив** в одну папку. Не переносите отдельные файлы из неё.
2. Откройте терминал в папке **respiration**, где находятся `desktop.py` и `app.py`.
3. Запустите оконную программу:

```bash
python desktop.py
```

На Linux/macOS команда может называться `python3`. В Windows также можно использовать `py desktop.py`.

Альтернативная команда для того же окна:

```bash
python app.py --desktop
```

### Браузерный интерфейс

```bash
python app.py
```

Откроется `http://127.0.0.1:8000`. Если браузер не открылся автоматически, вставьте этот адрес вручную. Терминал должен оставаться открытым; остановка сервера — **Ctrl+C**.

Если порт 8000 занят:

```bash
python app.py --port 8001
```

Для среды без графического дисплея:

```bash
python app.py --host 0.0.0.0 --port 8000 --no-browser
```

При обычном запуске сервер доступен только на вашем компьютере. Параметр `--host 0.0.0.0` открывает доступ по сети, поэтому используйте его только при необходимости. У каждой вкладки браузера свой независимый опыт.

### Если нет Tkinter

Проверить наличие:

```bash
python -m tkinter
```

На Ubuntu/Debian:

```bash
sudo apt install python3-tk
```

Или просто запускайте браузерный интерфейс — для него Tkinter не нужен.

## Как пользоваться

1. Введите процент кислорода в воздухе, **от 0 до 100**. Поддерживаются точка и запятая: `20.9` или `20,9`.
2. Нажмите **«Начать дыхание»**.
3. Наблюдайте за расширением/сужением лёгких, движением воздуха, переходом кислорода через стенку альвеолы в капилляр, связыванием с эритроцитами и доставкой клеткам.
4. Кнопка меняется на **«Приостановить»**, затем на **«Продолжить»**. Пауза останавливает время, анимацию и счётчики.
5. **«Сбросить»** обнуляет опыт и снова разрешает изменение концентрации.
6. **«Сохранить CSV»** выгружает таблицу значений с шагом 0,5 с и конечным состоянием. UTF-8 с BOM, разделитель `;`, десятичная запятая — удобно для Excel.

Пробел запускает опыт / ставит на паузу / продолжает, когда фокус не находится в поле ввода или другом интерактивном элементе.

### Показатели на экране

Все три показателя — **суммарные объёмы O₂ за время опыта**, в миллилитрах:

| Показатель | Значение |
|---|---|
| **Поступило в лёгкие** | Весь кислород, вдохнутый с воздухом с начала опыта |
| **Перешло в кровь** | Кислород, условно прошедший через стенку альвеол в кровоток |
| **Доставлено тканям** | Кислород, доставленный кровью клеткам организма |

Это **не** текущий запас кислорода внутри лёгких или сосудов. Поэтому счётчики не уменьшаются на выдохе. «Объём вдоха» снизу — текущий добавочный дыхательный объём, он меняется от 0 до 500 мл; остаточный объём лёгких не отображается. Счётчик полных циклов увеличивается после завершения вдоха и выдоха.

При **0% O₂** воздух и кровь продолжают двигаться, но все кислородные счётчики остаются нулевыми. Это математическая демонстрация, не описание состояния живого человека в бескислородной среде.

## Упрощённая математическая модель

Параметры:

- Дыхательный объём: **500 мл** на один вдох.
- Вдох: **2 с**; выдох: **3 с**.
- Частота: **12 циклов/мин**.
- Условная доля кислорода, переходящего в кровь: **20%**.
- Задержка газообмена: **0,6 с**.
- Дополнительное время транспорта кровью до тканей: **3 с**.

Обозначения: `t` — время опыта, `F = процент O₂ / 100`, `q = t % 5`, `n = floor(t / 5)`.

Добавочный объём лёгких плавно меняется по полукосинусоиде:

```text
Вдох, 0 ≤ q < 2:
V(q) = 500 × (1 − cos(π × q / 2)) / 2

Выдох, 2 ≤ q < 5:
V(q) = 500 × (1 + cos(π × (q − 2) / 3)) / 2
```

Для накопленного вдохнутого воздуха:

```text
A(t) = 500 × n + V(q)       во время вдоха
A(t) = 500 × (n + 1)        во время выдоха
A(t) = 0                   при t ≤ 0
```

Объёмы кислорода:

```text
I(t) = F × A(t)                поступило в лёгкие
B(t) = 0,20 × I(t − 0,6)       перешло в кровь
T(t) = B(t − 3)                доставлено клеткам
```

При отрицательном аргументе накопление равно нулю. Между кровью и тканями нет потерь; `B − T` — кислород, ещё находящийся в пути. Оставшиеся 80% вдохнутого кислорода условно выводятся с выдохом.

**Пример для 21% O₂:** после полного вдоха поступило `500 × 0,21 = 105 мл O₂`. Из него в кровь перейдёт `105 × 0,20 = 21 мл O₂`, затем тот же объём будет доставлен тканям. Первый вдох заканчивается на 2-й секунде; передача его кислорода в кровь заканчивается на 2,6-й, доставка тканям — на 5,6-й секунде (к этому времени уже начинается следующий вдох).

Используется аналитический расчёт, а не накопление «по кадрам»: итог не зависит от частоты экрана и промежуточных запросов. Часы опыта монотонные, время на паузе не учитывается.

## Ограничения

**Это учебная визуализация, не медицинский симулятор.** Коэффициент 20% и задержки заданы для наглядности. Модель не рассчитывает SpO₂, остаточный объём лёгких, CO₂, парциальные давления, сердечный выброс, насыщение гемоглобина или клеточный метаболизм. Реальный газообмен гораздо сложнее и не является линейным, особенно при крайних концентрациях кислорода.

Сердце и часть сосудов на схеме опущены. Размеры, количество частиц и цвета условные; кислородные маркеры на эритроцитах символизируют связь с гемоглобином, а не отдельные пузырьки газа в крови. Венозная кровь в действительности не синяя.

**Не используйте результат для оценки здоровья, медицинских расчётов или безопасности дыхательных смесей.**

## Файлы проекта

```text
respiration/
├── desktop.py          # Оконный интерфейс и цикл анимации, Python/Tkinter
├── svg_canvas.py       # Векторная отрисовка и движение частиц, Python
├── model.py            # Формулы, часы опыта, пауза/сброс, данные CSV
├── app.py              # Сервер браузерной версии, стандартная библиотека
├── interface.html      # Интерфейс браузера + общая векторная геометрия
├── README.md           # Эта инструкция
└── tests/
    ├── test_model.py   # Расчёты, баланс, задержки, пауза, геометрия
    ├── test_api.py     # API, независимые вкладки, CSV и валидация
    └── test_desktop.py # Проверка оконной версии (нужен дисплей)
```

В оконной версии из `interface.html` читается только геометрия SVG; JavaScript не выполняется. И расчёты, и анимация полностью на Python.

`interface.html` можно открыть отдельно для автономного предпросмотра: тогда формулы повторяются локально в JavaScript, что явно указано внизу страницы. **Для расчётов именно на Python запускайте `desktop.py` или `app.py`.** В автономном HTML-предпросмотре не нужны ни сервер, ни интернет.

## Проверка

Из папки проекта:

```bash
python -m unittest discover -s tests -v
```

20 автоматических тестов. В среде без дисплея две проверки Tkinter будут пропущены; остальные работают без графического интерфейса. Все 20 тестов были проверены с виртуальным дисплеем, а браузерный интерфейс дополнительно проверен в Chromium.
